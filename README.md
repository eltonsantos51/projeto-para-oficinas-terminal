Um sistema para oficinas de motocicletas, criada usando linguagem Python e SQLITE como banco de dados.

🛠️ Principais funcionalidades:
1. Cadastro de produtos
1. Controle de estoque
1. Cadastro de clientes
1. Registro de vendas
1. Cálculo de descontos e valores
1. Fechamento de caixa
1. Relatórios de produtos e clientes

💻 Tecnologias e conceitos utilizados:
1. Python
1. SQLite
1. Programação Orientada a Objetos
1. Modularização
1. Docstrings
1. Tratamento de exceções
1. Biblioteca Rich para apresentação dos dados no terminal
